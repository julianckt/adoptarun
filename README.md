# Adopt A Run

GPS-art community movement debuting in Hong Kong.

## Development

```bash
# Start Astro dev server (http://localhost:4321)
npm run dev

# Run unit tests and design checks
npm test

# Production build and safety checks
npm run build
```

## Sanity Studio

Sanity Studio is hosted on Sanity Cloud at [https://adoptarun.sanity.studio](https://adoptarun.sanity.studio).

```bash
# Run local Studio dev server (http://localhost:3333)
npm run studio:dev

# Build Studio static bundle
npm run studio:build

# Deploy Studio to Sanity hosting (adoptarun.sanity.studio)
npm run studio:deploy
```
