Collapse the Run Verification Pipeline

Strong ports & adapters
Files: src/lib/verification/ • prototype/scripts/modals.js • docs/spec/master-spec-sheet.md (§6)
Before: Shallow Verification Across Callers
                flowchart TD

One interface; spatial tolerance, point projection, and telemetry math hide behind the seam.

Problem: Spatial verification logic is shallow and scattered across Strava OAuth callbacks, GPX file parsing, and client modals.

Solution: Collapse spatial tolerances, date windowing, Haversine checks, and trajectory sampling behind one deep verification module.

Wins
  • ✓ Locality: spatial tolerances isolate in one place
  • ✓ Leverage: one engine verifies Strava and GPX
  • ✓ Pure in-process tests without mock DB
  • ✓ Interface shrinks; implementation absorbs 4 helpers
Candidate 02

Consolidate the Adopter Identity & Lifecycle Engine

Strong ports & adapters

Before: Leaking Identity Calculations

After: Deep Adoption Lifecycle Module
// Small, leveraged interface:
commitAdoption(input, store): Promise<Adoption>
registerWalkIn(input, store): Promise<Adoption>

Hidden: Seed 120 math • Pseudo jumps (+1..+4) • Initials check • Target dates • Multi-run suffixes (-2)
Storage seam with 2 adapters: in-memory mock for unit tests, Cloudflare D1 in production.

Solution: Encapsulate sequence seeds, initials hashing, target date calculations, and status transitions inside an Adoption Lifecycle module.

Wins
  • ✓ Locality: sequence jumping rules never leak
  • ✓ Leverage: one module serves signup, walk-ins, logs
  • ✓ Storage seam allows zero-DB fast testing
  • ✓ Lifecycle invariants strictly enforced
Candidate 03

Unify Route Telemetry & Map Synchronization

Worth exploring in-process
Files: src/components/map/ • prototype/scripts/map-scrub.js • prototype/log.html • prototype/routes.html
Before: Ad-Hoc DOM Map Scrubbing
window.initMapScrubber(...)
• Global Leaflet 'L' dependency
• Manual SVG clientX bounding box math
• Manual DOM marker creation & removal
Every consuming page must manually bind SVG scrub events to Leaflet coordinate arrays.
After: Deep Route Telemetry Module
<RouteTelemetryViewer />
props: { route, runTrace?, interactive? }
Hidden: Tile layer init • Bounding box fit • SVG scrub interpolator • Pulse tracer • Dark matter theme
One encapsulated React island; page authors never touch Leaflet instances or coordinate indexes.

Problem: Leaflet map initialization, CartoDB tile loading, SVG scrubber interpolation, and pulse markers are wired via fragile global DOM hooks.

Solution: Deepen into an encapsulated Route Telemetry Visualizer module that manages map lifecycle and bidirectional SVG scrub syncing.

Wins
  • ✓ Locality: scrub math and map lifecycle contained
  • ✓ Leverage: reused in Catalog, Log, and Modals
  • ✓ Parent Astro pages stay purely declarative
  • ✓ Deletes 3 disparate script listeners
